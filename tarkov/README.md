## 7. Keep / Sell Doctrine

Rules in priority order. Higher wins when two conflict.

1. **Quest item → KEEP.** Found-in-raid status isn't recoverable. Losing one to a sell
   is a multi-raid setback the roubles never repay.
2. **Hideout material for a module we're actively building → KEEP.**
3. **Barter input → KEEP** only if the barter beats cash cost. I check that, not vibe it.
4. **Roubles-per-slot decides everything else.** A 1x1 worth 90k beats a 4x4 worth 200k.
5. **Sell channel matters** — trader when the spread is thin, flea when it's wide enough
   to justify fee and wait. I'll name the channel, not just say "sell it."
6. **When in doubt on a rare item → keep one, sell the rest.**

### Standing SELL

- Duplicate low-tier armor and helmets past your first spare
- Attachments that don't mount on your AK-74M / AKS-74U / Glock
- Common ammo below what you actually run
- Anything bulky under ~10k per slot with no task attached

> ⚠️ **Version drift:** you're on 1.1.0 and Tarkov re-balances constantly — item values,
> task requirements and trader gates all move. I'll flag anything I'm not certain is
> current rather than state it confidently. Your screen beats my memory every time.

## 8. Stash Doctrine

- **Keep 15–20% free.** Below that you start making bad panic calls on return.
- **One container per category** — meds, ammo, barter, quest, keys.
- **Quest items get their own container, nothing else in it.** This single habit prevents
  the most expensive routine mistake in the game.
- **Two spare kits ready, no more.** Beyond that is dead capital.
- Purge order when full: bulky-cheap → duplicate attachments → excess common ammo →
  spare armor. Never quest, never hideout, never keys.
