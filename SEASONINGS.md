# Seasoning Reference

A living inventory of every seasoning, spice, herb, and blend in the kitchen.
Edit this file straight from your phone (GitHub app, or any text editor +
`git`/GitHub web UI) whenever stock changes or you invent something new.

**How to use this when creating a new dish or blend:**
1. Scan the [Quick Index](#quick-index) for flavor profile / heat level to find candidates.
2. Open the seasoning's full entry for pairing notes before you commit.
3. If you build a new blend, log it in [Blend Log](#blend-log) — ratios and all —
   so it can be reproduced later.
